# 暗棋 v0.2.3

單機網頁暗棋：跟電腦下（七個等級）或兩人同機，經典與連吃兩種玩法。打開就能玩，不用安裝、不用註冊。介面有中文和英文。

## 怎麼玩

- 用瀏覽器打開網址就能下；手機可以「加到主畫面」，之後像 app 一樣從主畫面打開。
- 打開過一次以後，沒有網路也能玩（背景音樂只有放過的曲子離線時聽得到）。
- 規則在開始頁的「規則」；名詞、電腦對手和積分的說明在「設定」最下面的「關於」。

## 隱私

帳號、積分和對局紀錄只存在你這台裝置的瀏覽器裡，不會傳到任何地方。清除瀏覽器資料，紀錄就會不見；可以到「紀錄」按「匯出紀錄」，存一份檔案當備份。
